# ShopMonitor 选品监控面板 · 产品说明书

> 版本：1.0.0（2026-08-09）｜形态：本地运行的全中文选品/竞品监控面板
> 数据：UUMit 免费电商数据（真实，0 扣费）+ 演示数据跑通全流程；平台真实数据按需配置

---

## 一、产品定位

面向电商运营/选品人员的本地化选品监控工具。覆盖「找词 → 看榜 → 比价 → 算利润 → 盯竞品 → 收藏备选 → 告警日报」完整流程，支持国内（京东/淘宝/拼多多/抖音/1688/快手）与跨境（Amazon/Shopee/TikTok Shop/AliExpress）平台。

## 三、数据来源说明

- **UUMit 免费电商数据**：大盘/热搜/联想词为真实数据，0 扣费；需要本机安装 uumit-agent 技能。
- **平台榜单/搜索**：官方开放平台适配器（国内 5 + 跨境 4）已内置，填凭证即走官方 API；未填自动降级演示数据（响应带 degraded=true，界面明确标注）。
- **自定义 JSON 数据源**：任何接口/文件转成统一 JSON 即可接入，无需改代码。
- **演示数据（mock）**：用于试跑全流程，真实数据未配置时自动降级，不中断。

## 四、快速开始

1. 解压分享版 → 双击「创建桌面快捷方式.bat」→ 桌面图标双击启动（或直接双击「启动-选品监控.bat」）。
2. 打开浏览器 http://127.0.0.1:8010/ 即见面板（演示数据可跑通全部功能）。
3. 点亮真实数据：接口文档 → 配置中心 → 填平台凭证 / AI Key / 汇率 / 模板。
4. 用完可双击「停止服务.bat」，或让服务常驻后台。

## 五、部署与分享

- 本地单机：绿色便携版（内置 Python，免安装）。
- 正式安装包：Inno Setup 编译 setup.exe（安装后自动建桌面快捷方式）。
- 无服务器数据包：GitHub Actions 每天自动生成 7 平台数据 + GitHub Pages 免费托管，客户填一次地址即可（见 docs/方案E-无服务器数据包.md）。

## 六、常见问题

- **端口被占用**：改 配置文件.env 的 SHOPMONITOR_PORT。
- **数据是演示的？**：响应 degraded=true 即演示；配置对应平台凭证后自动切真实。
- **UUMit 数据不可用**：需本机安装 uumit-agent 技能；不影响其余功能。
- **数据存哪里**：本机 data/ 目录（关注/告警/选品库/快照/报告）。

## 七、技术栈

Python 3.12 + FastAPI + SQLite + 纯前端面板（无框架，单 HTML）。单机本地运行，数据不出本机。

## 八、目录说明

- shopmonitor/：后端 + 前端（api/ 接口、collectors/ 平台适配器、panel.html 面板、bigscreen.html 大屏）
- tools/：启动器/构建分享包/数据源工具
- assets/：应用图标与截图

- dist/：分享版（绿色便携）

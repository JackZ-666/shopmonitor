# 电商监控维度指南（基于主流电商运营/竞品监控需求调研）

> 依据：电商运营监控指标、竞品监控工具功能（价格/销量/评价/活动/库存/排名）、选品分析体系（市场规模/竞争度/利润空间）等公开资料整理。

## 电商卖家最需要监控的 8 个维度

| # | 维度 | 为什么重要 | ShopMonitor 对应 |
|---|------|-----------|----------------|
| 1 | **价格** | 竞品降价 24h 内是流量重分配窗口；秒杀/优惠券直接影响转化 | price / original_price / promo_text / is_promo + 历史与涨跌 |
| 2 | **销量与趋势** | 识别上升期、避开已爆品；判断真实需求 | sales + /history + /change（涨跌） |
| 3 | **排名** | 榜单/搜索位次变化 = 流量变化前兆 | rank（榜单位次 / 搜索位次） |
| 4 | **评价** | 新增差评/评分下滑 = 质量风险信号 | rating / review_count + 历史跟踪 |
| 5 | **库存** | 缺货/预售预警，避免断货或压货 | stock_status |
| 6 | **店铺** | 供应链与售后质量判断 | shop_name / shop_rating |
| 7 | **品牌/类目** | 类目市场规模与竞争度分析 | brand / category |
| 8 | **利润** | 客单价、毛利率决定是否值得做 | 报告模板利润估算列（按成本公式填） |

## 选品判断逻辑（报告模板内建建议）
- 销量 > 1000 且价格带 50-300 元（大众快消）优先看；
- 价格频繁变动 = 竞争激烈，慎入；
- 评分 < 4.0 或差评集中在质量 = 供应链风险；
- 店铺数少且搜索量大的关键词 = 蓝海机会；
- 只盯上升期，不碰已爆品。

## 与 API 的对应
- `GET /api/v1/rank/{platform}`：榜单/热卖（覆盖价格、销量、排名、评价、库存、店铺、促销）
- `GET /api/v1/search/{platform}`：关键词搜索位次（覆盖核心关键词排名监控）
- `GET /api/v1/product/{platform}/{id}/history`：价格/销量/评分/评论数历史
- `GET /api/v1/product/{platform}/{id}/change`：涨跌分析（降价/销量↑↓/评论↑↓）
- `GET /api/v1/report/compare`：一键选品对比表（14 列）

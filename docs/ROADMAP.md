# 产品改善路线图（对标同类监控面板）

> 参考对象：蝉妈妈（抖音电商数据）、任拓情报通（全域电商大盘）、Tool4seller（亚马逊卖家工具）、
> Shopify 竞品跟踪/盯价哨兵（价格监控）、优麦云（关键词排名）、蓝海罗盘（AI 拆解）、Shein 商家数据中心（自定义看板）。

## 已具备（2026-08-09）
- 大盘数据：10 项指标、淘宝/京东平台对比、销售趋势（日期/季/年聚合）、报告导出（MD/CSV）
- 热搜选词：抖音热搜、百度热搜（6 类）、淘宝联想词、热搜报告导出
- 监控告警：价格/销量/排名/评分/评论/库存/促销/上新 8 类，Webhook + JSONL
- 商品价格历史曲线、14 列选品对比表（md/csv/xlsx）、中英双路径 API

## 待补充（按优先级）
### P0（数据已有，工作量小，建议先做）
1. **日报/周报自动摘要**：每天定时把监控结果 + 大盘 + 热搜汇总成 Markdown 日报，推送到企业微信/钉钉/飞书（对标蝉妈妈定时日报）。
2. **排名趋势图**：关键词/榜单排名变化曲线（已有 history 数据，缺图表展示）。
3. **多平台热搜一键报告**：抖音+百度+微博等聚合进一张报告（已有报告框架，扩充来源）。
4. **面板主题/深色模式 + 大屏模式**：对标 Shein 商家数据中心大屏，F11 全屏展示核心指标。

### P1（需要 UUMit 星火免费 AI 额度 / 数据源）
5. **AI 选品分析** ✅ 已实现（ai_analysis.py）：输入类目/关键词，结合大盘+热搜+联想词生成选品建议/关键词/风险提示。大模型用 OpenAI 兼容 API（豆包火山方舟 / 智谱 GLM / 通义 DashScope / DeepSeek 任选），配置 `AI_LLM_API_KEY` 即可；未配置返回 needs_key 不阻塞。
6. **AI 竞品对比摘要**：选定竞品商品，自动生成价格/销量/评价差异分析（对标 Competitor Tracker）。

### P2（需要平台凭证/付费数据源）
7. **新品/上新监控**：监控竞品店铺新品上架（需要店铺级数据源）。
8. **优惠券/活动监控**：竞品发券、参加大促活动提醒（需要平台活动数据）。
9. **被跟卖提醒**（亚马逊）：Buy Box 被抢提醒（需要 Amazon SP-API）。
10. **差评内容解析**：低星评价内容抓取与分类（需要评价数据源）。
11. **品类占比/品牌 TOP/区域分布大屏**：类目份额、品牌榜、地域分布可视化（需要类目/地域数据，UUMit 免费接口暂不支持过滤）。

### P3（商业化）
12. **订阅套餐**：按平台数/关键词数/告警数/报告次数分级（免费版 + 付费版）。
13. **多语言**：报告/面板英文版（跨境卖家）。
14. **多店铺账号体系**：多用户注册、各自看板（上架 UUMit 后可做）。

- **日报自动摘要（P0-1）**：POST/GET /api/v1/监控/日报，大盘+热搜+今日告警+监控概况合成 Markdown，落盘 data/daily-reports/ 并推送企业微信/钉钉/飞书 Webhook；巡检后自动触发（每天一次，幂等）。

- **深色模式 + 数据大屏（P0-4）**：面板支持浅色/深色主题切换（localStorage 记忆）；新增数据大屏页 http://127.0.0.1:8010/大屏（深色全屏、10 项大盘指标 + 平台对比 + 抖音/百度热搜 + 成交额趋势，60 秒自动刷新，对标 Shein 商家中心数据大屏）。

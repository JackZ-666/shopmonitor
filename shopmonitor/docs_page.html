① 平台数据配置（三选一）
方式操作配置文件.env 里的项
方式一：UUMit 免费数据
（零配置，推荐先用）		大盘/热搜/联想词自动可用，0 扣费UUMIT_SKILL_DIR（留空自动探测）
方式二：自定义 JSON 数据源
（最省事，10 分钟）		下载数据源模板 → 把商品榜单按模板填好 → 保存为 json 文件/接口地址 → 填到下面任一平台项 → 重启SHOPMONITOR_JD_RANK_URL / _PDD_ / _DOUYIN_ / _TAOBAO_ / _SHOPEE_ / _AMAZON_ / _ALIEXPRESS_RANK_URL
方式三：官方 API
（合规，需申请）		京东联盟 union.jd.com（需开通 goods.query 权限）；淘宝登录 Cookie；拼多多/抖音开放平台（需商家资质）JD_UNION_APP_KEY / JD_UNION_SECRET_KEY；TAOBAO_COOKIE
⑥ 官方开放平台凭证（国内：抖音商城/淘宝/拼多多/1688/快手；跨境：TikTok Shop/Amazon/Shopee/AliExpress） '
平台申请入口要填的配置项
抖音商城（抖店）op.jinritemai.com（需企业认证）DOUYIN_MALL_APP_ID / DOUYIN_MALL_SECRET
淘宝开放平台open.taobao.comTAOBAO_APP_KEY / TAOBAO_APP_SECRET
拼多多开放平台open.pinduoduo.comPDD_CLIENT_ID / PDD_CLIENT_SECRET
1688 开放平台open.1688.comALIBABA_APP_KEY / ALIBABA_APP_SECRET
快手电商开放平台open.kwaixiaodian.comKUAISHOU_APP_KEY / KUAISHOU_APP_SECRET
TikTok Shoppartner.tiktokshop.com（TikTok Shop Partner Center 应用，需商家授权）TIKTOK_SHOP_APP_KEY / TIKTOK_SHOP_APP_SECRET / TIKTOK_SHOP_ACCESS_TOKEN
Amazon PA-APIwebservices.amazon.com/paapi5（需 AWS Key + 联盟 PartnerTag）AMAZON_ACCESS_KEY / AMAZON_SECRET_KEY / AMAZON_PARTNER_TAG
Shopee 开放平台open.shopee.com（应用 Partner Key + 商家授权）SHOPEE_PARTNER_ID / SHOPEE_PARTNER_KEY / SHOPEE_ACCESS_TOKEN / SHOPEE_SHOP_ID
AliExpress 联盟open.aliexpress.com（联盟应用 + 推广者授权）ALIEXPRESS_OPEN_APP_KEY / ALIEXPRESS_OPEN_APP_SECRET / ALIEXPRESS_OPEN_ACCESS_TOKEN
通用说明部分接口还需下面的 Token / 扩展参数（在配置中心可填）DOUYIN_MALL_ACCESS_TOKEN / ALIBABA_ACCESS_TOKEN / KUAISHOU_ACCESS_TOKEN / TAOBAO_ADZONE_ID
凭证填好后在下方「配置中心」保存即生效（自动重启）。官方 API 通常需要企业资质，个人可先用 自定义 JSON 或 UUMit 免费数据。
② AI 选品分析配置（可选）
步骤说明
1. 申请 Key豆包火山方舟 / 智谱 GLM / 通义千问 / DeepSeek 任选（都有免费额度，OpenAI 兼容）
2. 填入配置配置文件.env：AI_LLM_API_KEY=sk-xxx（BASE_URL / MODEL 留空自动识别）
3. 使用面板「AI 选品分析」输入关键词一键分析；或 POST /api/v1/ai/选品分析
③ 告警推送配置（可选，自动推送到手机）
步骤说明
1. 建群机器人企业微信 / 钉钉 / 飞书 群里添加「群机器人」，复制 Webhook 地址
2. 填入配置配置文件.env：SHOPMONITOR_WEBHOOK_URL=https://qyapi.weixin.qq.com/...
3. 效果降价/缺货/新品上榜等告警 + 每日日报自动推送
④ 套餐配置（免费/Pro/企业）
套餐关注数上限AI配置
free5关SHOPMONITOR_PLAN=free（默认）
pro50开SHOPMONITOR_PLAN=pro
enterprise不限开SHOPMONITOR_PLAN=enterprise
改完保存 → 重启服务生效。配置状态可在面板「设置」页查看。
